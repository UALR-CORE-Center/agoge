# Contributing to This Project

Thank you for your interest in contributing! We welcome improvements, bug fixes, documentation updates, and new features that improve the project.

## Ways to Contribute
You can contribute in several ways:
* Reporting bugs
* Suggesting new features
* Improving documentation
* Submitting pull requests
* Helping review issues or pull requests

## Reporting Bugs
If you discover a bug, please open a GitHub Issue and include:
* A clear description of the problem
* Steps to reproduce the issue
* Expected behavior
* Screenshots or logs if applicable
* Your environment (OS, Python version, etc.)

## Suggesting Features
Feature requests are welcome. Please open an issue describing:
* The problem you are trying to solve
* Why the feature would be useful
* Any potential implementation ideas

## Pull Request Process
1. Fork the repository.
2. Create a new branch from `main`.
```
git checkout -b feature/my-feature-name
```
3. Make your changes.
4. Ensure the code builds and tests pass.
5. Commit your changes with clear messages.
```
git commit -m "Add feature: improved mitigation scoring"
```
6. Push to your fork and open a Pull Request.

## Coding Guidelines

Please follow these general guidelines:

* Keep changes focused and minimal
* Write clear, readable code
* Include comments where helpful
* Add tests when appropriate
* Update documentation if behavior changes

## Commit Message Style

Use clear commit messages:

```
fix: correct mitigation scoring bug
feat: add adversary budget simulation
docs: update installation instructions
```

## Code of Conduct

Please be respectful and constructive when interacting with others. Harassment, discrimination, or hostile behavior will not be tolerated.

## Questions
If you have questions about contributing, feel free to open a GitHub Issue for discussion.

We appreciate your help in improving this project!
