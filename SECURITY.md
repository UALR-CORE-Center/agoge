# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in this project, please report it responsibly.

Do not open a public GitHub issue for security vulnerabilities.

Instead, please report the issue privately to:
**[security@bastazo.com](mailto:security@bastazo.com)**

Include the following information if possible:
* Description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Suggested mitigation (if known)

We will acknowledge receipt of your report within **72 hours**.

## Responsible Disclosure
We follow a responsible disclosure process:
1. The vulnerability is reported privately.
2. The maintainers investigate and validate the issue.
3. A fix is developed.
4. The fix is released.
5. The vulnerability may be publicly disclosed after remediation.

## Scope
Security reports may include issues related to:
* Authentication or authorization
* Data exposure
* Privilege escalation
* Dependency vulnerabilities
* Remote code execution
* Denial of service conditions

## Security Updates
Security patches will be released as soon as possible after validation.

Users are encouraged to stay up to date with the latest releases.

## Supported Versions
At this time, only the latest release is actively supported with security updates.
